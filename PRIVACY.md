# Privacy / 隐私说明

ExamLex 0.1.0 does not require an account and does not upload searches, scores, vocabulary or personal data to a server. The empty dictionary is created at `%LOCALAPPDATA%\\ExamLex\\lexicon.db`; saved vocabulary is stored at `%LOCALAPPDATA%\\ExamLex\\glossary.json`. Calculator inputs are processed in memory only.

Internet access is needed only when the developer restores NuGet dependencies or reads linked documentation. This version contains no analytics, login or dictionary-download service. Future features must update this policy before introducing external network requests.
