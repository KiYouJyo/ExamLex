# Security Policy

Supported: ExamLex 0.1.x development branch. Report vulnerabilities privately using GitHub's repository security-advisory channel when available, rather than exposing exploit details in an issue. Do not upload personal dictionary files, certificates, secrets, screenshots of private content, or signing keys.

Vocabulary imports are not yet implemented. When they are added, treat input files as untrusted and apply size limits, schema validation and parameterized SQL.
